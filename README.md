## 📌 Note on Git Commit History
Hi! This GitHub repository is created for our final project submission. 

During the first few weeks of development, our group decided to write and combine our code locally. We shared our `.cpp` files through Google Drive and tested them on one main laptop. We did this because we were afraid of making mistakes with Git merge conflicts while we were still building the complex parts (like the Linked Queue and Classes). 

Once the core system was stable and running fine, we created this official repository. Each member then independently pushed their completed modules here for the final integration.

## 📖 Project Overview
This is a C++ Mini Information System for managing hospital patients and staff records. Following the project guidelines, we manually created everything without using the C++ STL library. 
Our system includes:
* Dynamic Non-Primitive (DNP) Linked Queue
* Bubble Sort (Sorting)
* Binary & Linear Search (Searching)
* Try-Catch Exception Handling

## ⚙️ How to Compile and Run
Please use **Dev-C++** to compile and run this system, as required by the assignment guideline.

1. Download all files from this repository.
2. Make sure the `.cpp` file and all the `.txt` files (like `hospital_database.txt`, `patient_credentials.txt`) are in the **exact same folder**.
3. Open `Group5_HospitalSystem.cpp` using **Dev-C++**.
4. Press `F11` (Compile & Run).
